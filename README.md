# ArenaGauntlet

Fight ten escalating rounds of hordes and champions in a Greek colosseum. Hire allied war companies, gear up at the arena merchants between battles, and face Mithrix in the final showdown. A Risk of Rain 2 game mode.

**[Download the latest release](https://github.com/Kuriyukihime/ArenaGauntlet/releases/latest)** · [Full description](package/README.md) · [Changelog](package/CHANGELOG.md)

## Install

1. Install the mods listed under `dependencies` in [package/manifest.json](package/manifest.json). Any Risk of Rain 2 mod manager can install them.
2. Download `ArenaGauntlet-x.y.z.zip` from the latest release.
3. Import the ZIP in your mod manager (in r2modman: Settings → Import local mod), or copy the `BepInEx` folder from the ZIP into your Risk of Rain 2 folder.

In multiplayer, every player needs the same version.
