# ArenaGauntlet cover artwork

Generated with the built-in image_gen tool for the 0.22.0 package refresh. The source is arena-cover.png; arena-cover-prompt.txt records the exact prompt. This is illustrative promotional artwork, not an in-game screenshot.

Art direction: a charged survivor facing a towering stone champion in a Greek colosseum, with cyan impact energy, an orange sunset and large readable ARENA GAUNTLET lettering. It replaces the static temple insignia.

scripts/make_icon.py only downsizes this square source to the required 256px Thunderstore icon. It does not redraw or reinterpret the art. Keep the source in this project so future packaging retains the selected artwork.
